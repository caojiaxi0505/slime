> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a manual CLI that runs real-AGS L0 (create/exec) and L1 (normalize → init → gold patch → evaluate) without calling `generate()` or requiring SGLang.

**Architecture:** `examples/claudecode_ags/smoke/ags_smoke.py` loads one official row, normalizes it, and drives `make_sandbox` + workspace init + `dispatch.evaluate`. Unit tests cover loaders/CLI only; live AGS is opt-in by the operator.

**Tech Stack:** asyncio, argparse, optional pyarrow for parquet; existing Path A modules.
